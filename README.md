# drkianmaleki.com

Source code for [drkianmaleki.com](https://drkianmaleki.com) — personal portfolio of Kian Maleki, PhD.

## Committed files

| File | Purpose |
|---|---|
| `index.html` | Main homepage. Equations and figures are inline SVG between `<!-- generated:… -->` markers, produced by `tools/build.js` |
| `styles.css` | Full visual styling. Color tokens at the top: paper theme in `:root`, Midnight theme under `:root[data-theme="dark"]` |
| `scripts.js` | Theme toggle (Midnight by default, Paper remembered per browser), weekly phrase rotation, equation placement in the title block, Figure 1 animation, footer year |
| `tools/` | `build.js` and `package.json`: regenerate the inline equation and figure SVGs in `index.html` (see below); `tools/node_modules/` is ignored |
| `resume.html` | Redirect to Data Scientist resume PDF |
| `cv.html` | Redirect to Academic CV PDF |
| `CNAME` | GitHub Pages custom domain |
| `favicon.svg` | Adaptive browser favicon: dark ring on light tab bars, blue ring on dark ones (generated by design scripts) |
| `favicon.ico` | Fallback favicon for browsers without SVG favicon support (generated by design scripts) |
| `documents/` | Resume and CV PDFs |
| `assets/` | Profile photo, logo PNGs for both themes (`kian-logo-production.png`, `kian-logo-midnight.png`), and favicon PNGs (generated by design scripts) |

## Design toolchain (local only)

The `design/` folder contains Python scripts that generate the logo and favicon assets.
It is listed in `.gitignore` and never committed — only the generated output files in `assets/` and the root favicons are committed.

See [design/README.md](design/README.md) for setup and usage.

## Regenerate equations and figures

The typeset equations and the two SVG figures are stored inline in `index.html`, so the site needs no build step.
To change them, edit the TeX strings or the timeline data at the top of `tools/build.js`, then:

```bash
cd tools
npm install
node build.js
```

This rewrites the marked blocks in `index.html`. Commit the regenerated `index.html`.

## Run locally

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

This site is hosted on GitHub Pages. Push to `main` and GitHub Pages deploys automatically.

```bash
git add .
git commit -m "your message"
git push
```
