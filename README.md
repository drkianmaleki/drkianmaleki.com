# drkianmaleki.com

Source code for [drkianmaleki.com](https://drkianmaleki.com) — personal portfolio of Kian Maleki, PhD.

## Committed files

| File | Purpose |
|---|---|
| `index.html` | Main homepage |
| `styles.css` | Full visual styling |
| `scripts.js` | Weekly phrase rotation, mobile navigation, footer year |
| `resume.html` | Redirect to Data Scientist resume PDF |
| `cv.html` | Redirect to Academic CV PDF |
| `CNAME` | GitHub Pages custom domain |
| `favicon.ico` | Browser favicon (generated by design scripts) |
| `documents/` | Resume and CV PDFs |
| `assets/` | Profile photo, logo PNG, and favicon PNGs (generated by design scripts) |

## Design toolchain (local only)

The `design/` folder contains Python scripts that generate the logo and favicon assets.
It is listed in `.gitignore` and never committed — only the generated output files in `assets/` are committed.

See [design/README.md](design/README.md) for setup and usage.

## Run locally

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

This site is hosted on GitHub Pages. Push to `main` and GitHub Pages deploys automatically.

```bash
git add .
git commit -m "your message"
git push
```
